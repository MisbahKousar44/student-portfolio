# My Personal Portfolio

This is my personal portfolio website developed for the Web Programming Languages course (CSC337).

## Website Pages

- Home: My introduction and future goals.
- Hobbies: My favourite hobbies and games.
- Favourite Media: Photography, images and videos.
- Contact: Contact information, map and contact form.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Website Features

- Responsive layout
- Sticky header
- Table hover effects
- Keyboard accessibility
- Embedded YouTube videos
- Embedded Google Map
